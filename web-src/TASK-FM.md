# ТЗ: профессиональный файловый менеджер (FilesView)

Полностью переработать `C:\hostpanel\web-src\src\views\FilesView.vue` в духе
проводника Windows, сохранив стартовый `route.query.path`, дефолт `me.www_root`
и ограничение корней (fm_roots на сервере). Путь импорта контролов:
`../components/ui/UiSelect.vue` и т.п. (кастомные select/checkbox УЖЕ есть).
Стилевые классы бери из app.css (.card, .btn, .pill, .chip, .mono...);
специфичные для проводника стили — scoped в конце файла.

## API (всё существует, бэкенд готов)

- GET  /api/files?path=P            → {path, entries:[{name,type:'dir'|'file',size,mtime,mode,owner,target?}], roots:[...]}
- POST /api/files/mkdir             {path: <папка/новая>}
- POST /api/files/rename            {path, new_name} (только переименование на месте)
- POST /api/files/move              {paths: [...], dest: <папка>}   — НОВЫЙ
- POST /api/files/copy              {paths: [...], dest: <папка>}   — НОВЫЙ
- POST /api/files/delete            {paths: [...]}
- POST /api/files/chmod             {path, octal}
- POST /api/files/extract           {path} → {dest}
- POST /api/files/zip               {paths: [...], dest: 'имя.zip'} → {dest}
- POST /api/files/upload?dest=<dir>  multipart, поле file (можно несколько —
  append по одному файлу в один FormData; большие файлы — по одному)
- GET  /api/files/read?path=        → {content} (редактирование)
- POST /api/files/save              {path, content}
- GET  /api/files/download?path=    → скачивание через downloadFile()
- /api/files?path=P ответ содержит и allowed roots для дерева.

Существующие модалки/логика старого файла переиспользуй (chmod, extract,
переименование, редактор через CodeEditor) — не потеряй ни одну функцию
старого FilesView.

## Обязательные возможности

1. **Левая панель (дерево/закладки)**: корни из ответа API + текущий путь;
   раскрытие папок по клику (лениво, /api/files), выделение текущей папки.
2. **Панель инструментов**: ← назад (история), ↑ вверх, крошки пути (клик по
   сегменту — переход), поиск/фильтр по имени (живой), кнопки: Новая папка,
   Новый файл, Загрузить, Скачать выбранные, Вид (список/крупные значки),
   сортировка (имя/размер/дата/тип; asc/desc кликом по заголовку).
3. **Список файлов**: папки первыми, иконки по типу (расширение: img →
   картинка-плитка?), имя, размер, изменён, права, владелец.
4. **Выделение**: клик — один, Ctrl+клик — добавить/снять, Shift+клик —
   диапазон, Ctrl+A — все, клик по пустому — сброс. Двойной клик по папке —
   открыть, по файлу — редактировать (если текстовый) иначе скачать.
5. **Контекстное меню (правый клик)** на объекте: Открыть, Редактировать,
   Скачать, Копировать путь, Вырезать, Копировать, Переименовать, Архивировать
   в zip, Распаковать (для архивов .zip/.tar.gz/.tgz), Права (chmod), Удалить
   (confirmDlg). На пустом месте: Обновить, Новая папка, Новый файл,
   Загрузить файлы, Вставить (если буфер не пуст). Закрытие: клик вне/Esc.
   Позиция — у курсора, не выходя за край окна.
6. **Буфер обмена (внутренний)**: Вырезать (cut) / Копировать (copy) объекты,
   «Вставить» в текущую папку → /api/files/move или /api/files/copy; после —
   обновить список. Не переносить объект сам в себя.
7. **Drag&drop**:
   - Перетаскивание ФАЙЛОВ С КОМПЬЮТЕРА на область списка → загрузка в
     текущую папку (dataTransfer.files, по одному FormData с progress через
     XHR? достаточно без прогресса + тост «загружено N файлов»).
   - Перетаскивание строки НА ПАПКУ в списке или на папку в левом дереве →
     move (draggable=true на строках; подсветка папки-приёмника).
8. **Загрузка**: кнопка «Загрузить» = скрытый input file multiple; также
   drag&drop из п.7. Показывать краткий лог загрузок (имя → ок/ошибка).
9. **Удаление/скачивание нескольких**: выделенные → Удалить (confirmDlg со
   списком имён, до 5 + «…»), Скачать выбранные → если 1 файл download, если
   несколько → /api/files/zip во временное имя + download zip.
10. **Редактирование**: модалка с CodeEditor (как сейчас) + «Сохранить».
11. **Статусная строка внизу**: «показано N объектов · выбрано M · путь».
12. Мобильная адаптация: колонки с data-l не обязательны, главное — не
    разваливалась вёрстка.

## Технические требования

- Vue 3 script setup TS, компоненты ui/ (UiCheckbox не обязателен),
  UiIcon (name из набора), AppModal, confirmDlg, toast/toastErr,
  api/apiForm/downloadFile из api/client.
- Никаких inline-строк HTML; context menu — отдельный div с absolute
  позиционированием + Teleport не нужен (внутри вью).
- Таймеры/слушатели (document click для контекст-меню, dragleave) чистить в
  onBeforeUnmount.
- Сортировка/режим вида сохранять в localStorage.
- НЕ менять компоненты ui/*, app.css, роутер, другие вью.
- В конце: `cd C:\hostpanel\web-src && npm run build` — 0 ошибок.
