# ТЗ 1: Файловый менеджер — 3 доработки

Файл: C:\hostpanel\web-src\src\views\FilesView.vue (прочитать ЦЕЛИКОМ).
Не трогать другие файлы, ui/*, app.css (scoped-стили в конце файла — ок).

## 1. Убрать недоступную папку "var" из левого дерева
Дерево строится из корней (me.www_root=/var/www, me.home=/opt/hostpanel).
В дереве для КАЖДОГО корня отображается родительская крошка (например
"var" над "www") — она недоступна для навигации. Убрать эти
родительские элементы: дерево должно начинаться прямо с корней.
Найдите место, где пушатся родительские сегменты, и удалите эту логику.

## 2. Контекстное меню правым кликом на ПАПКИ В ДЕРЕВЕ
Узлы дерева (папки) должны поддерживать @contextmenu — то же меню, что и
для строк списка (переиспользуйте существующий механизм контекст-меню и
его пункты; для узла дерева применямы: Открыть (раскрыть/перейти),
Новая папка (в этой папке), Загрузить сюда, Архивировать/Распаковать/Права/
Переименовать/Удалить — всё, что применимо к папке; переиспользуйте
существующие функции, передавая путь узла). Выделение узла при правом
клике. Меню должно закрываться кликом вне/Esc (как существующее).

## 3. Расширенный диалог прав (chmod) как в FileZilla
Заменить текущую простую модалку chmod на расширенную:
- Три группы чекбоксов (UiCheckbox): «Права владельца», «Группы»,
  «Публичные права» — каждая: Чтение / Запись / Выполнять.
- Поле «Числовое значение» (numeric, 4 знака: специальные биты + octal),
  двусторонне связано с чекбоксами (чекбокс → пересчёт числа; ввод числа —
  пересчёт чекбоксов; поддержать спец-биты setuid/setgid/sticky — 3
  доп. чекбокса «SUID», «SGID», «Sticky» над группами).
- Чекбокс «Перенять права на вложенные» (только для папок) + radio
  (UiRadio-группа name="chmodrec"): «Применить ко всем файлам и каталогам» /
  «Только к файлам» / «Только к каталогам».
- Для рекурсивного применения вызывать /api/files/chmod для КАЖДОГО
  вложенного объекта (получить список через /api/files?path=<папка>
  рекурсивно, до 500 объектов; для файлов — только chmod, для папок — chmod
  + продолжить рекурсию согласно radio). Показывать прогресс (счётчик
  «обработано X из Y») и ошибки построчно. Числовое значение для каталога:
  если чекбокс «выполнять» стоит у группы — каталогу добавлять x-бит
  (как chmod -R с X): каталогам присваивать numeric c x-битами, файлам —
  без, если исходный файл не был исполняемым (упрощение: каталогам
  octal | 0o111).
- Кнопки ОК / Отмена; ОК с :disabled во время применения.
- Для папки также поддержать применение БЕЗ рекурсии (radio может быть
  не выбрано — просто chmod самой папки).
