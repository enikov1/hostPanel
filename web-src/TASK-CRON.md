## API (существует, менять бэкенд НЕ нужно)

- GET /api/cron → { jobs: [{id, expr, command, comment, enabled}...],
  system_jobs: [...], auto, auto_cron, ssl_auto, ssl_auto_cron }
- POST /api/cron/save { jobs, auto, auto_cron, ssl_auto, ssl_auto_cron }
- GET /api/cron/log?command=<команда> → { lines: [...] } — строки журнала
  в формате: `=== 2026-11-05 03:00:01 запускаю: <команда>` … `[код завершения: N]`
- POST /api/cron/run {command} / POST /api/cron/save и т.п. — как в текущем коде.

## Что добавить

1. **Сводка-панель сверху** (карточка): пилюли «задач: N», «включено: M»,
   «ближайший запуск: <дата-время>» (минимум по next-run всех включённых задач),
   короткое пояснение для новичка (уже есть — сохраните).
2. **Следующий запуск каждой задачи** — вычисляется на клиенте:
   напишите helper nextRunCron(expr: string): Date | null в файле (или в
   src/lib/cronNext.ts) для стандартных 5-полей: поддержать `*`, `*/N`,
   число, списки `1,15`, диапазоны `1-5`, дни недели 0–7 (0 и 7 = вс),
   месяцы 1–12. Алгоритм: перебор минут от текущего времени вперёд на 366
   дней по минутам — НЕ делать (медленно); делайте умный расчёт по полям
   (минуты → часы → дни → месяцы). Допустимо упрощение: перебор минут
   с шагом до 366*24*60 итераций с быстрым отсевом по месяцам/дням.
   В строке задачи: «следующий запуск: сегодня в 03:00» /
   «5 ноя, 04:15» (fmt через humanRel + дату).
3. **Статус последнего запуска в строке задачи**: при загрузке списка для
   каждой включённой задачи (параллельно, Promise.all) запросить
   /api/cron/log?command=…, взять последний блок: дата запуска и код
   завершения. Показать пилюлю: зелёную «последний запуск: ок, 5 ноя 03:00»,
   красную «ошибка (код 1)», серую «ещё не запускалась». Не блокировать
   рендер списка (подгружать после).
4. **Готовые задачи в один клик** (карточка «Шаблоны задач» под тулбаром,
   раскрывается/сворачивается): пресеты для новичка — клик открывает
   СУЩЕСТВУЮЩУЮ модалку добавления, предзаполнив expr+command+comment:
   - «Ежедневный бэкап всех сайтов» — expr «0 3 * * *», команда
     `hcp-backup --all`
   - «Еженедельная очистка старых логов» — expr «0 4 * * 0», команда
     `find /var/log/hostpanel -name '*.gz' -mtime +30 -delete`
   - «Очистка кеша apt (по воскресеньям)» — expr «0 5 * * 0», `apt-get clean`
   - «Проверка доступности сайта раз в 5 минут» — expr «*/5 * * * *»,
     команда `curl -fsS http://СУБДОМЕН/ -o /dev/null || echo FAIL`
     (домен попросить вписать при добавлении — оставьте плейсхолдер)
   - «Удаление временных файлов раз в час» — expr «0 * * * *»,
     `find /tmp -type f -mtime +7 -delete`
   У каждого пресета: иконка UiIcon, название, короткое описание, расписание
   человекочитаемо (cronHuman). Кнопка «Добавить» на пресете.
5. **Строки задач**: добавьте к существующим кнопкам ничего — но убедитесь,
   что «Запустить сейчас» и «Журнал» видны; комментарий задачи показывать
   под командой (мелким шрифтом); expr показывать mono + human-расшифровка.
6. Пустое состояние — сохранить прежнее («Задач пока нет…» + кнопка).
